项目简介

ai-edge-monitor 是一个面向边缘 AI 推理部署的性能评估系统。 给定一台边缘设备和 AI 模型，它能告诉你：能不能跑、能跑多快、瓶颈在哪、怎么优化。

本页面是一个纯前端实时看板。在本地运行 ai-edge-monitor run --duration 300 --web-dashboard 后， 本页面会自动连接本地 http://localhost:8080 的 API， 实时展示当前电脑的 CPU、内存、GPU、温度、功耗等指标。

如何使用这个看板

本地模式：在本地运行 ai-edge-monitor run --web-dashboard 后，刷新本页面即可看到本机实时指标。

在线演示： https://gypg.github.io/ai-edge-monitor/ 每 5 分钟由 GitHub Actions runner 自动采集并刷新，无需安装。
